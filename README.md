# Task-4-CodeAlpha_HotelReservationSystem

This is a Java-based Hotel Reservation System developed as part of the CodeAlpha Internship.

## 📌 Project Description
The Hotel Reservation System is designed to help users search, book, and manage hotel room reservations. The system provides different room categories and allows users to manage their bookings easily.

## ✨ Features
- Search available hotel rooms
- Book hotel rooms
- Cancel reservations
- Room categories: Standard, Deluxe, and Suite
- Payment simulation
- View booking details
- Manage room availability

## 🛠️ Technologies Used
- Java
- OOP Concepts
- File Handling / Database

## ▶️ How to Run
1. Download or clone the project.
2. Open the project in a Java IDE such as Eclipse.
3. Compile and run the main Java file.
